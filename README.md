# Orbit para Homebrew

E-mail, calendário e assistente de IA num app nativo para Mac.

```bash
brew install --cask jeanmenezesmagalhaes/orbit/orbit
```

Atualizar:

```bash
brew upgrade --cask jeanmenezesmagalhaes/orbit/orbit
```

Desinstalar (com `--zap` apaga também os dados locais do Orbit):

```bash
brew uninstall --cask --zap jeanmenezesmagalhaes/orbit/orbit
```

Precisa de Mac com Apple Silicon e macOS 14 ou mais novo. Use o nome completo acima: o Homebrew oficial já tem outro app chamado `orbit`.

Este repositório só guarda a cask e o app pronto (assinado e notarizado) nas releases.
